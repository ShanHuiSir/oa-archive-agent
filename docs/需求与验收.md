# 需求与验收对应

附件共一份赛题说明和十份示例办公文件。示例文件用于输入验证，不是标准答案，也不提供官方分类准确率基准。比赛附件不随公开仓库发布。

| 赛题要求 | 对应实现 | 验证方法 |
| --- | --- | --- |
| 文件夹批量导入及多格式 | 路径扫描、浏览器选择文件与文件夹；DOCX、XLSX、XLS、PDF、常见图片及 TXT | 六份原创模拟资料、十份附件样本 |
| 文件名和正文/OCR识别 | 原生正文提取、本地 RapidOCR、本地规则分类、可选 DeepSeek 结构化分类客户端 | 本地模式的原文依据和OCR记录；模型接口实测状态另列 |
| 部门、类型、生成日期 | 企业枚举约束、日期格式核验、模型自评阈值及人工复核 | 独立样例字段预期及缺失日期案例 |
| 企业自定义模板 | 可编辑部门、类型、模板字段含义与文件命名占位符 | 归口单位/制发日期/材料类别样例 |
| 规则重命名分类归档 | 部门/类型/年月目录；文件名模板；内容哈希防重；复制归档 | 副本与原件SHA256一致、冲突及原件修改测试 |
| 台账搜索、Excel导出 | SQLite持久台账、关键词过滤、Excel导出和完整归档ZIP | 查看真实导出并核对记录条数 |
| 简易图形化界面及可执行产品 | 回环地址本地服务与浏览器界面；Windows独立打包入口 | 解压后执行OAArchive.exe进行验证 |
