# 演示资料

本视频使用六份原创模拟办公资料，输入在samples目录。正文中的企业、人员、业务事项均为虚构。实际运行使用本地规则模式及本地OCR；模型增强入口独立保留，不把规则输出标成模型成果。

真实操作顺序：业务问题 → 企业字段设置与资料导入 → 本地识别 → 查看扫描件正文与字段依据 → 补录缺失日期 → 确认归档 → 搜索法务部 → 导出筛选台账 → 导出全量台账和完整归档包。

本轮导入6份、自动完整提取5份、待复核1份，人工确认后归档6份。日期缺失样例补录2026-04-09，属于模拟资料负责人提供的信息，未计作自动识别日期。原件及归档副本已逐份核对SHA256。

视频由Chromium真实浏览器会话录制，保留实际鼠标移动、点击、输入、滚动、状态变化与下载；指针叠层仅跟随真实浏览器鼠标事件。没有使用预制结果、伪造API响应或静态界面冒充处理。剪辑仅改变真实操作片段速度并添加章节、神经语音和同步字幕。

旁白为zh-CN-XiaoxiaoNeural中文神经语音。语音合成只发送公开解说文字，不发送文件正文、API Key或参赛联系方式。SRT与ASS字幕使用语音服务句级时间戳。字幕放在画面底部留白区域。

`原始操作录屏.webm`为原始真实画面；`录屏事件.json`记录原片章节位置；`演示解说词.txt`、`演示字幕.srt`、`演示字幕.ass`及`旁白音轨.mp3`便于修改。`视频实测记录.json`记录最终视频格式、时长和剪辑对应关系。XLSX、ZIP、JSON均来自本轮实际操作。
